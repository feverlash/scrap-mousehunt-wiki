# Phase Zombie

The Phase Zombie is a breed of mouse found in the Burroughs Rift. It is known to drop Brain Bits and Terre Ricotta Potion as loot.

## Preferred Cheese

Phase Zombie can be attracted using any Standard String Cheese or Undead String Emmental.


## Hunting Strategy

Phase Zombie can be attracted by using either:

- Standard String Cheese when the Mist Meter is in Yellow and Green Zone.
- Undead String Emmental

Using Brain Charm or Super Brain Charm increases the attraction rate of Phase Zombie.

Rift power type is effective against Phase Zombie while all others are less effective.


## History and Trivia

- 9 September 2014: The Phase Zombie was released as part of the Burroughs Rift location.
- 13 January 2015: The Phase Zombie gained its preference to Brain Charm and Super Brain Charm with the start of Zombie Invasion Week 2015.

# Dread Knight Mouse

The Dread Knight Mouse is a breed of mouse found in the Bristle Woods Rift. It is the Rift counterpart of Terror Knight Mouse.

## Preferred Cheese

The Dread Knight Mouse has been found to be especially attracted to String Cheese, Ancient String Cheese and Runic String Cheese, to the point that any other kind of cheese will simply not suffice.

# Oxygen Baron Mouse

Oxygen Baron Mouse is a mouse found in Sunken City. It can drop Oxygen Canister as loot.

## Hunting Strategy

Oxygen Baron Mouse is only available when Docked in Sunken City.

Fishy Fromage is required to attract this mouse

Hydro is the only power type working against this mouse.

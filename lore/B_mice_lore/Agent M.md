## Cheese Preference

The Agent M is only attracted to Cloud Cheesecake.


## Hunting Strategy

Only Law traps are effective against the Agent M, all other power types are ineffective. The Agent M can only be encountered on a Law Garrison.


## Loot


### Floating Islands's Island Based Loot

When found on a Low Altitude Island or a High Altitude Island, depending on the buffs present, the Agent M can drop the following loot:


| Item | Condition |
| --- | --- |
| Sky Glass | Always drops Boosted by Sky Glass Formations and Loot Caches |
| Sky Ore | Always drops Boosted by Sky Ore Deposit and Loot Caches |
| Cloud Curd | Drops when a Cloud Curd Bonus is present Can be boosted by Loot Caches |
| Corsair's Curd | Drops when a Pirate Den is present Can be boosted by Loot Caches |


additionally, this mouse can drop Simple Orbs

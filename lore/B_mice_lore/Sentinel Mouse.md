# Sentinel Mouse

> "Sentinel" redirects here. For other uses, see Sentinel (disambiguation).

The Sentinel Mouse is a breed of mouse found in the Fiery Warpath location. It can be attracted and caught only during Wave Two. They are not known to drop any loot.

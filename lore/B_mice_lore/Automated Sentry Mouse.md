# Automated Sentry Mouse

The Automated Sentry Mouse is a breed of mouse found in the Burroughs Rift. It is known to drop Mist Canisters as loot.

## Preferred Cheese

Automated Sentry Mouse can be attracted using any Standard String Cheese.


## Hunting Strategy

Automated Sentry Mouse can be attracted when the Mist Meter is in No Mist Zone.

Rift power type is effective against Automated Sentry Mouse while all others are less effective.

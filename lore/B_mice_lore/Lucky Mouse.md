# Lucky Mouse

> "Lucky" redirects here. For more uses, see Luck (disambiguation).

The Lucky Mouse is a breed of mouse found during various Luck events. It is known to drop Luck Charm, Super Luck Charm, Extreme Luck Charm and Ultimate Luck Charm as loot.

This page was last updated to represent preferences for the most recent appearance of the Lucky Mouse (16 March 2022). Event preferences and loot can be found in the Event Participation section below.

# Cutthroat Cannoneer Mouse

The Cutthroat Cannoneer Mouse is a breed of mouse found on the Floating Islands, on any island with a Sky Pirate Den present.

## Cheese Preference

The Cutthroat Cannoneer Mouse is only attracted to Sky Pirate Swiss Cheese.


## Hunting Strategy

All powertypes except Rift and Parental are effective against the Cutthroat Cannoneer Mouse. The Cutthroat Cannoneer Mouse can only be encountered on an island with one or multiple Sky Pirate Den present and active.


## Loot


### Floating Islands's Sky Pirate Loot

Cutthroat Cannoneer Mouse has a chance to drop Storm Cell if Rocket Boosters have been attached on the Hunter's Dirigible and the following loot depending on the buffs present:


| Item | Condition |
| --- | --- |
| Sky Glass | Always drops Boosted by Sky Glass Formations and Loot Caches |
| Sky Ore | Always drops Boosted by Sky Ore Deposit and Loot Caches |
| Sky Pirate Seal | Always Drops The amount a mouse drops depends on the mouse caught. |
| Cloud Curd | Drops when a Cloud Curd Bonus is present Can be boosted by Loot Caches |


Additionally, the Cutthroat Cannoneer Mouse can drop the following loots as well:

- Bottled Wind
- Cyclone Stone

# Record Keeper's Assistant Mouse

The Record Keeper's Assistant Mouse is a breed of mouse found in the Bristle Woods Rift. It is the Rift counterpart of Keeper's Assistant Mouse.

## Preferred Cheese

The Record Keeper's Assistant Mouse has been found to be especially attracted to String Cheese, Ancient String Cheese and Runic String Cheese, to the point that any other kind of cheese will simply not suffice.

## Hunting Strategy

Only Rift type traps are effective against Record Keeper's Assistant Mouse, all other power types are ineffective.

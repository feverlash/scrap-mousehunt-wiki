# Skeletal Champion Mouse

The Skeletal Champion Mouse is a breed of mouse found in the Bristle Woods Rift. It is the Rift counterpart of Skeleton Mouse.

## Preferred Cheese

The Skeletal Champion Mouse has been found to be especially attracted to String Cheese, Ancient String Cheese and Runic String Cheese, to the point that any other kind of cheese will simply not suffice.

## Hunting Strategy

Only Rift type traps are effective against Skeletal Champion Mouse, all other power types are ineffective.

The Rift Antiskele Charm can be used to repel the Skeletal Champion Mouse from your trap.

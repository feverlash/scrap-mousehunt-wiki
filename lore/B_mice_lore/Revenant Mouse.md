# Revenant Mouse

The Revenant Mouse is a breed of mouse found in the Burroughs Rift. It is known to drop Mist Canisters and Terre Ricotta Potion as loot.

## Preferred Cheese

Revenant Mouse can be attracted using any Standard String Cheese or Undead String Emmental.


## Hunting Strategy

Revenant Mouse can be attracted by using either:

- Standard String Cheese when the Mist Meter is in Green Zone.
- Undead String Emmental

Rift power type is effective against Revenant Mouse while all others are less effective.


## History and Trivia

- 9 September 2014: The Revenant Mouse was released as part of the Burroughs Rift location.

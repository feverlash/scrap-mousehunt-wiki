# Clumsy Carrier Mouse

Clumsy Carrier Mouse is a mouse found in Sunken City. It can drop Oxygen Canister as loot.

## Hunting Strategy

Clumsy Carrier Mouse is only available when Docked in Sunken City.

Fishy Fromage is required to attract this mouse

Hydro is the only power type working against this mouse.

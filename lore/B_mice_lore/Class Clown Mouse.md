## Cheese Preference

Class Clown Mouse is only attracted to Apprentice Ambert.


## Hunting Strategy

The Class Clown Mouse can only be attracted during the Arcane phase of the Final Exam.

Arcane power type is very effective against Class Clown Mouse.
Shadow power type is effective against Class Clown Mouse.
All other types are ineffective.

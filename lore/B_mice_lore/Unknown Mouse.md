# Unknown Mouse

An Unknown Mouse is a mouse that has yet to be caught by a hunter. These mice are usually either new or very rare. Unknown mice are displayed with a placeholder image of a question mark, which is later replaced by a silhouette of the mouse after it has been caught for the first time. Despite being unknown, the MouseHunt Info Page will still provides the power and power type of the mouse. It will also include either a description of the mouse or a note saying that the hunter has not yet discovered a location where the mouse resides.

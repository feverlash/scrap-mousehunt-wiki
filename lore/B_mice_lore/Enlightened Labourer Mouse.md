# Enlightened Labourer Mouse

The Enlightened Labourer Mouse is a breed of mouse found in the Furoma Rift. It is the Rift counterpart of Worker Mouse.

## Preferred Cheese

The Enlightened Labourer Mouse has been found to be attracted to Brie String, Magical String and Maki String Cheese, to the point that any other kind of cheese will simply not suffice.


## Hunting Strategy

Only Rift type traps are effective against Enlightened Labourer Mouse, all other power types are ineffective.

## Preferred Cheese

Cranky Caterpillar mice have been found to be especially attracted to String Cheese, to the point that any other kind of cheese will simply not suffice.


## Hunting Strategy

The Cranky Caterpillar Mouse is weak to Rift Traps. It can only be attracted by String Cheese.

The Cranky Caterpillar Mouse is only available when rage in the Crazed Clearing section in Whisker Woods Rift is between 0-24.

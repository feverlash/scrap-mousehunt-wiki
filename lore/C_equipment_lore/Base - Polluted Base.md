# 🛡️ Polluted Base

> **Classification**: General Base  
> **Power / Luck**: 500 Power | 5 Luck  
> **Title Requirement**: Hero  
> **Acquisition Cost**: 1,434,000 Gold1 Polluted Base Blueprints800 Pollutinum60 Radioactive Sludge30 Scrap Metal

## 📜 Lore & Rekayasa Perangkap

> A simulated spill was safely poured onto this base to mask it from its surroundings. Hard to distinguish between the actual spill itself, it allows the pollution of the Toxic Spill to seep through it, adding a chance for mice to drop a Radioactive Curd. Additionally, the Polluted Base will react with Polluted Charms, increasing the core radiation and using that energy to add extra Luck!

## 🔨 Asal-Usul & Perakitan (Crafting/Shoppe)
The Polluted Base can be purchased from the Trapsmith in Toxic Spill for:

- 1,434,000 Gold
- 1 Polluted Base Blueprints
- 800 Pollutinum
- 60 Radioactive Sludge
- 30 Scrap Metal

It cannot be refunded.

The Polluted Base (if unintentionally smashed) can be reassembled from Polluted Base Parts.

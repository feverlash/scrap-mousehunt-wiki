# Count Vampire Mouse

The Count Vampire Mouse is a breed of mouse found in the Burroughs Rift. It is known to drop Mist Canisters and Terre Ricotta Potion as loot.

## Preferred Cheese

Count Vampire Mouse can be attracted using any Standard String Cheese or Undead String Emmental.


## Hunting Strategy

Count Vampire Mouse can be attracted by using either:

- Standard String Cheese when the Mist Meter is in Yellow and Green Zone.
- Undead String Emmental

Rift power type is effective against Count Vampire Mouse while all others are less effective.

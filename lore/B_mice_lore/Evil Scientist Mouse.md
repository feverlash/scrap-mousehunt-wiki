# Evil Scientist Mouse

The Evil Scientist is a breed of mouse found in the Burroughs Rift. It is known to drop Mist Canisters as loot.

## Preferred Cheese

Evil Scientist Mouse can be attracted using any Standard String Cheese.


## Hunting Strategy

Evil Scientist Mouse can be attracted when the Mist Meter is in No Mist Zone.

Rift power type is effective against Evil Scientist Mouse while all others are less effective.


## History and Trivia

- 9 September 2014: The Evil Scientist Mouse was released as part of the Burroughs Rift location.

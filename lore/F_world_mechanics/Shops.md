# ⚙️ Shops

> **Hukum Dunia / Mekanik Cerita**: Shops

## 📜 Konsep Lore & Aturan Permainan

# Shops


## Overview

Shop is the mechanic that let the Hunter exchange Gold and other Currencies to various types of items in the game.

Shops are generally tied to locations, but sometimes when an Event without a specific location is running, that event can add a set of items to all shops aound the Kingdom.


### Shop types

- Cheese Shoppe

- Trapsmith

- Charm Shoppe

- General Store

- Cartographer

- King's Cart (formerly Prize Shoppe)

- Premium Shop

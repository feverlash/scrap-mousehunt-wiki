# Amplified Grey Mouse

The Amplified Grey Mouse is a breed of mouse found in the Burroughs Rift. It is known to drop Mist Canisters as loot.

## Preferred Cheese

Amplified Grey Mouse can be attracted using any Standard String Cheese.


## Hunting Strategy

Amplified Grey Mouse can be attracted when the Mist Meter is in No Mist Zone.

Rift power type is effective against Amplified Grey Mouse while all others are less effective.

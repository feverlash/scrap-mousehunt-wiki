# Clockwork Timespinner Mouse

The Clockwork Timespinner Mouse is a breed of mouse found in the Bristle Woods Rift. It is the Rift counterpart of Spider Mouse.

## Preferred Cheese

The Clockwork Timespinner Mouse has been found to be especially attracted to String Cheese, Ancient String Cheese and Runic String Cheese, to the point that any other kind of cheese will simply not suffice.

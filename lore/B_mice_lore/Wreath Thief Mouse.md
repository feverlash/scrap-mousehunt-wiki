## History and Trivia

- 20 December 2010: The Wreath Thief Mouse was released as part of the Great Winter Hunt 2010 event.
- 25 June 2013: The Wreath Thief Mouse gained a vulnerability to Law power type traps with the release of Varmint Valley. It also lost vulnerability to all other trap types.
- 8 October 2013: The Wreath Thief Mouse's vulnerability to other trap types was restored. Since no event involved this mouse in the meantime, the temporary mistake had only been visible via the mouse description page.
- 13 December 2016: The points/gold for Wreath Thief Mouse were changed.

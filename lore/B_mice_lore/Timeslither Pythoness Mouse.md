# Timeslither Pythoness Mouse

The Timeslither Pythoness Mouse is a breed of mouse found in the Bristle Woods Rift. It is the Rift counterpart of Gorgon Mouse.

## Preferred Cheese

The Timeslither Pythoness Mouse has been found to be especially attracted to String Cheese, Ancient String Cheese and Runic String Cheese, to the point that any other kind of cheese will simply not suffice.

## Hunting Strategy

Only Rift type traps are very effective against Timeslither Pythoness Mouse, all other power types are ineffective.

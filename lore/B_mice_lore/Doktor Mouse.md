# Doktor Mouse

The Doktor Mouse is a breed of mouse found in the Burroughs Rift. It is known to drop Mist Canisters as loot.

## Preferred Cheese

Doktor Mouse can be attracted using any Standard String Cheese.


## Hunting Strategy

Doktor Mouse can be attracted when the Mist Meter is in No Mist Zone.

Rift power type is effective against Doktor Mouse while all others are less effective.

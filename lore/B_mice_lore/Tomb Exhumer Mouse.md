# Tomb Exhumer Mouse

The Tomb Exhumer Mouse is a breed of Event mouse that can be found in the Burroughs Rift when hunting with Undead String Emmental cheese.

## Preferred Cheese

The Tomb Exhumer Mouse is only attracted to Undead String Emmental.


## Hunting Strategy

Rift power type is very effective against Tomb Exhumer Mouse while all others are of normal effectiveness.


## History and Trivia

- 17 May 2017: The Tomb Exhumer Mouse was introduced as part of the Zombie Invasion 2017 event.

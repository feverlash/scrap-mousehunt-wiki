# Lycanoid

The Lycanoid is a breed of mouse found in the Burroughs Rift. It is known to drop Mist Canisters and Terre Ricotta Potion as loot.

## Preferred Cheese

Lycanoid can be attracted using any Standard String Cheese or Undead String Emmental.


## Hunting Strategy

Lycanoid can be attracted by using either:

- Standard String Cheese when the Mist Meter is in Green Zone.
- Undead String Emmental

Rift power type is effective against Lycanoid while all others are less effective.


## History and Trivia

- 9 September 2014: The Lycanoid was released as part of the Burroughs Rift location.

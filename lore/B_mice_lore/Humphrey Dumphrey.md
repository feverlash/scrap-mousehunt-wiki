## Cheese Preference

Humphrey Dumphrey can be attracted using any Standard Cheese.


## Hunting Strategy

Humphrey Dumphrey is only available when the stage is writing.

Forgotten power type is effective against Humphrey Dumphrey.
All other types are ineffective.


## Loot

Humphrey Dumphrey can drop:

- Draft Derby Curd

With Leather Bound Cover, the following loot is added to the pool:

- Cleverness Clam
- Crop Coin
- Ingenuity Grub
- Inspiration Ink
- Mythical Mulch
- Pond Penny
- Papyrus Seed
- Parable Papyrus

## History and Trivia

- 14 October 2014: The Shortcut Mouse is released as part of the Halloween 2014 event.
- 13 October 2016: The description for the Shortcut Mouse was changed. The previous description read:

> Zooming through the Corn Maze, zipping through the Haunted Manor and flying through the Pumpkin Patch. This guy has been around the Terrortories so much so that he knows all the little secret paths, trap doors and alternate routes allowing him to rush through it all in record time! Candy collection has never been so easy!Capturing this mouse will let you in on the closest secret shortcut, advancing you three spaces forward while traversing the Haunted Terrortories.

- 13 October 2021: The description of the Shortcut Mouse is changed to remove/update references to the previous Halloween Sandcastle event.

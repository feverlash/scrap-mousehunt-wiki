# Cute Cloud Conjurer Mouse

## Cheese Preference

- On a Hydro Island or a Hydro Hideaway, the Cute Cloud Conjurer Mouse is only attracted to Cloud Cheesecake.
- In a Hydro Reservoir, the Cute Cloud Conjurer Mouse is only attracted to Extra Rich Cloud Cheesecake.


## Hunting Strategy

Only Hydro traps are effective against the Cute Cloud Conjurer Mouse, all other power types are ineffective. The Cute Cloud Conjurer Mouse can only be encountered on a Hydro Island, a Hydro Hideaway, or a Hydro Reservoir.


## Loot

When found on a Low Altitude Island or a High Altitude Island, depending on the buffs present, the Cute Cloud Conjurer Mouse can drop the following loot:

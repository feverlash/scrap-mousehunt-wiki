# 🛡️ Chrome Base

> **Classification**: General Base  
> **Power / Luck**: 1250 Power | 25 Luck  
> **Title Requirement**: Archduke  
> **Acquisition Cost**: #Obtained Via

## 📜 Lore & Rekayasa Perangkap

> This shining slab of solid Cerulean Chrome has been expertly engraved with a design so intricate and exquisite that it transcends mere beauty and actually imbues this base with extraordinary powers! Its many swirling crevices have the ability to harness and absorb some of the power from each mouse that it encounters. Hunt by hunt, this base charges itself on that power until it reaches a critical point where it coalesces into a physical manifestation of that power in the form of a Chrome Skull!
> The Chrome Base has the following special effects while using it:
> • Spawns a Chrome Skull every 300 hunts
> • Provides a 100% chance to roll up any armed Chrome Charm into its next, more powerful version

## 🔨 Asal-Usul & Perakitan (Crafting/Shoppe)
The Chrome Base can be purchased from the Trapsmith in Cerulean Skyport for:

- 20,000,000 Gold
- 300 Cerulean Chrome Ingot

It requires the Hunter to complete the Liberate the Cerulean Skyport from Captain Crook adventure to purchase.

It cannot be refunded.

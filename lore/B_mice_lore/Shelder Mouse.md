# Shelder Mouse

The Shelder Mouse is a breed of mouse found in the Rodentia region. They are known to drop Ancient Relics and Divine Orbs as loot.

## Preferred Cheese

Standard Cheeses provides very poor attraction for the Shelder Mouse.
SUPER|brie+ provides improved attraction for the Shelder Mouse.
Galleon Gouda reduces the mouse population in S.S. Huntington IV and provides the highest attraction rate for the Shelder Mouse.

Note: The Shelder Mouse is not attracted to Shell Cheese despite being mentioned in the description of that cheese.
